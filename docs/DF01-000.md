# Commit Log Rule & Instruction

> **CRITICAL INSTRUCTION**: Always add new commit logs at the top of the commit log file, directly under the document header, in reverse chronological order (newest entry first).

## Log Format Standard

Each log entry must follow the format below:

```markdown
## [SERIAL_ID]: [Title] | YYYY-MM-DD
- Detailed description of functional or UI change 1.
- Detailed description of functional or UI change 2.
- Modified files list / API endpoints alignment.
```
