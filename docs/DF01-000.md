# Commit Log Rule & Instruction

> **CRITICAL INSTRUCTION**: Always add new commit logs at the top of the commit log file, directly under the document header, in reverse chronological order (newest entry first).

---

## Log Format Standard

Each log entry must follow the format below:

```markdown
## [SERIAL_ID]: [Title] | YYYY-MM-DD
- Detailed description of functional or UI change 1.
- Detailed description of functional or UI change 2.
- Modified files list / API endpoints alignment.
```

## DF03: Slug-Based Product Detail Page Navigation | 2026-08-13
- Changed product detail navigation path query parameter from `did` to `slug` inside `ProductCard.jsx`, `FeaturedProductSlider.jsx`, and `ScentFinderQuiz.jsx`.
- Updated `ProductDetail.jsx` page to support resolving product details by retrieving `slug` from query parameters (`searchParams.get('slug')`) and matching by slug.
- Staged and committed changes.

## DF02: Add-to-Cart Validation & Simple Product UI Optimization | 2026-08-13
- Implemented strict size/variation validation in Zustand store `handleAddToCart` action.
- Hidden size selection controls in `ProductCard.jsx` for simple products (those with no variations or a single 'Full Bottle' variation).
- Disabled the "Add to Cart" button for variable products when no variation is selected, displaying "Select Size" with reduced opacity.
- Staged and committed changes.
